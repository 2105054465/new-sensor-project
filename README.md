# 传感器信号处理优化题

## 背景

设备以 10 Hz 接收一帧 `22 × 32` 的 8 位压力阵列。左右各 `22 × 16` 个点，处理目标包括：

1. 启动时估计空载基线；
2. 提取总压力、列峰值、连续有效行、Top-3 行压力占比；
3. 区分人体的长条分散压力与局部按压；
4. 使用 5 帧投票和离床迟滞稳定占用状态；
5. 使用相邻帧差分检测翻身等运动。

`sensor_signal.c/.h` 是从实际 STM32 项目中剥离的独立基线版本，不依赖 HAL 或 RTOS。输入矩阵按行优先排列，数值范围为 `0..255`。

## 候选人任务

在不改变公开 API 的前提下优化实现，并说明取舍。可以调整内部数据结构；如认为某项可观察行为不合理，也可以修改，但必须写明原因并补充测试。

重点考察方向：

- 降低每帧 CPU 开销，给出优化前后的复杂度或实测数据；
- 降低栈/静态内存占用，适配资源受限 MCU；
- 处理计数溢出、边界阈值、冷启动有人、传感器坏点及噪声；
- 改善状态机、命名、模块边界和可测试性；
- 为关键边界和时序行为增加单元测试；
- 可选：在保持整数实现的情况下改善信号滤波与自适应基线。

请不要仅做格式化或编译器优化参数调整。

## 接口约定

```c
SensorProcessor processor;
SensorResult result;

SensorProcessor_Init(&processor);
SensorStatus status = SensorProcessor_Process(&processor, frame, &result);
```

- 校准阶段返回 `SENSOR_STATUS_CALIBRATING`；
- 正常处理返回 `SENSOR_STATUS_READY`；
- 空指针返回 `SENSOR_STATUS_BAD_ARGUMENT`；
- `SensorProcessor` 保存跨帧状态，同一个实例不可被多个线程无锁并发调用。
